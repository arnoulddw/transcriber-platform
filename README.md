# Transcriber Platform has moved

Transcriber Platform is now **Transcriber**, at **[github.com/arnoulddw/transcriber](https://github.com/arnoulddw/transcriber)**.

This repository is archived and no longer updated.

- **Running an existing installation?** Follow [Upgrading from transcriber-platform](https://github.com/arnoulddw/transcriber#upgrading-from-transcriber-platform). Your data and accounts are kept.
- **Using the Docker image?** Switch from `arnoulddw/transcriber-platform` to [`arnoulddw/transcriber`](https://hub.docker.com/r/arnoulddw/transcriber). The old image name is still published for a few releases.
